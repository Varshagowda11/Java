Language
Language is a medium to communicate between two entities.
Entities: Which exist in the world and occupy space.
Example: Human beings communicate with each other using language.

Programming language is a medium to communicate between humans and machines/system.
Example:
- Human gives instructions to a machine.
- The machine understands the instructions through a programming language.

Types of Programming Languages
1. Machine Level Language (Low-Level Language)
2. Assembly Level Language (Mid-Level Language)
3. High-Level Language

2. Types of Programming Languages
1. Machine Level Language (Low-Level Language)
- It is understandable by machines.
- It is a binary language.
- It has two representatives:
  - 0
  - 1
- It is near to machines and far from humans.

2. Assembly Level Language (Mid-Level Language)
- It is in a human-readable format.
- We have a set of instructions called mnemonics and keywords (predefined words).
- Examples: ADD, MOV, SUB, MUL, etc.
Difficulties:
- Machines cannot understand Assembly Language directly.
- We need to convert Assembly Language (AL) into Machine Level Language (MLL).
- We need software called an Assembler.
- 8086 instructions are an example.
Advantages:
- Easier for humans to write and understand.

3. High-Level Language
- It is in a human-readable format.
- Examples: Java, Python, C, C++ and C#.
- Machine cannot understand High-Level Language directly.
- We need to convert High-Level Language (HLL) into Machine Level Language (MLL).
- We need software:
  - Compiler
  - Interpreter
Advantages:
- Easier to learn.
- Easier to write.
- Easier to debug and maintain.

Two Types of HLL
1. POPL
2. OOPL

POPL – Procedure Oriented Programming Language
- Focuses on procedures/functions.
- Example: C.
- No OOPS.
OOPL – Object Oriented Programming Language
- Focuses on objects.
- Examples: Java, Python, C++.
Java is a High-Level Object-Oriented Programming Language.

3. History of Java
James Gosling is known as the Father of Java.
History
1. James Gosling was working in Sun Microsystems as a software developer.
2. One day, he came up with an idea to develop a programming language which could run on any system.
3. He needed a team and called it the Green Team.
4. He started a project. The project name was Green Project.
5. He finished and published it in the year 1991 as Green Talk.
Naming of Java
1. One day, they stood outside a company with a coffee shop. They thought their programming language idea would grow like a tree.
2. So, they kept the tree name called Oak.
3. Oak was already a company name with a business, so they could not continue using it.
4. Then they changed the name in 1995 to Java.
5. Java is a coffee name. When they were building the project, they drank coffee called Java coffee.
6. Then, in 2010, the Oracle company took over Sun Microsystems.
7. So, Java comes under Oracle (with the Java chair/name under Oracle).
Important timeline:
- 1991 – Green Project / Green Talk
- 1995 – Java
- 2010 – Oracle acquired Sun Microsystems

### 5\. Platform Dependent and Platform Independent

### Platform Dependent

* A program that is dependent on a particular platform is called platform dependent.

* Example: C language.

Example:

* Smith writes a program on a 32-bit Windows system.

* It may not run directly on a 64-bit or another platform.

* We need platform-specific compilation.

### Platform Independent

* A program that is not dependent on a particular platform is called platform independent.

* Example: Java.

Example:

* Smith writes a Java program on a 32-bit Windows system.

* The same program can run on 32-bit Linux, 64-bit Windows and other platforms using the appropriate JVM.

Note:

* C is a platform-dependent language.

* Java is platform independent but dependent on JDK/JRE (as written in the notebook).

* Java is platform independent because of Bytecode.

### 6\. JDK (Java Development Kit)

JDK = Java Development Kit

JDK is software that contains many sub-softwares inside it.

* It contains JRE and Compiler inside it.

* It provides an environment to both write and run programs.

### JDK Structure


### 7\. JRE (Java Runtime Environment)

* It is a sub-software of JDK.

* It contains JVM and in-built packages inside it.

* It provides an environment to run Java programs.

### 8\. Compiler

* It is a sub-software of JDK.

* It is used to convert from HLL to MLL.

* It will read the code once.

### 9\. JVM (Java Virtual Machine)

* It is a sub-software of JRE.

* It contains JIT and Interpreter inside it.

* It is a machine used to run Java programs.

### 10\. JIT (Just-In-Time Compiler)

* It is a sub-software of JVM.

* It will speed up the interpreter.

### 11\. Interpreter

* It is a sub-software of JVM.

* It is used to convert HLL to MLL.

* It will read the code line by line.

### Java Notes – Variables in Java

### 1\. What is a Variable?

A variable is a container used to store data in a program.

* It is used to store values.

* Every variable has a name and a data type.

* The value of a variable can be changed during program execution.

Syntax:

```java
dataType variableName = value;
```

Example:

```java
int age = 22;
String name = "Varsha";
```

Here:

* `int` – Data type

* `age` – Variable name

* `22` – Value

### 2\. Types of Variables in Java

Based on where they are declared, variables are mainly classified into three types:

* Local Variable

* Instance Variable

* Static Variable

Sometimes, instance and static variables are collectively called global variables in beginner-level explanations. However, Java technically calls them fields or member variables.

### 3\. Local Variable

Definition: A variable declared inside a method, constructor or block is called a local variable.

Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int a = 10;  // Local variable
        int b = 20;  // Local variable

        System.out.println(a);
        System.out.println(b);
    }
}
```

Characteristics:

* Declared inside a method, constructor or block.

* Scope is limited to the block where it is declared.

* Memory is associated with method/block execution.

* No default value is provided.

* We must initialize it before using it.

### 4\. Global Variables

Global variables are commonly used to refer to variables declared inside a class but outside methods.

There are two types:

### A. Instance Variable (Non-static Variable)

Definition: A variable declared inside a class but outside methods, without using the `static` keyword, is called an instance variable.

Example:

```java
class Student
{
    int age = 22;  // Instance variable

    public static void main(String[] args)
    {
        Student s = new Student();

        System.out.println(s.age);
    }
}
```

Output:

```text
22
```

Characteristics:

* Declared inside a class and outside methods.

* Does not use the `static` keyword.

* Each object gets its own copy.

* Gets a default value.

* Accessed using an object reference.

### B. Static Variable (Class Variable)

Definition: A variable declared inside a class using the `static` keyword is called a static variable.

Example:

```java
class Student
{
    static String college = "DBIT";

    public static void main(String[] args)
    {
        System.out.println(Student.college);
    }
}
```

Output:

```text
DBIT
```

Characteristics:

* Declared inside a class using `static`.

* Only one shared copy exists per class (per class loader).

* Memory is associated with the class.

* Gets a default value.

* Can be accessed using the class name.

### 5\. Difference Between Local, Instance and Static Variables

| Feature       | Local                     | Instance         | Static       |
| ------------- | ------------------------- | ---------------- | ------------ |
| Declaration   | Inside method/block       | Inside class     | Inside class |
| Keyword       | No special keyword        | No static        | static       |
| Memory        | During execution          | With object      | With class   |
| Default value | No                        | Yes              | Yes          |
| Copy          | Per declaration/execution | Per object       | Shared       |
| Access        | Directly within scope     | Object reference | Class name   |

### 6\. One Program to Understand All Three

```java
class VariableDemo
{
    int a = 10;          // Instance variable
    static int b = 20;  // Static variable

    public static void main(String[] args)
    {
        int c = 30;      // Local variable

        VariableDemo obj = new VariableDemo();

        System.out.println(obj.a);
        System.out.println(b);
        System.out.println(c);
    }
}
```

Output:

```text
10
20
30
```

### Java Notes – Data Types in Java

### 1\. What is a Data Type?

A data type specifies what type of value a variable can store.

* It defines the size of data.

* It specifies the type of value stored in a variable.

* It helps the compiler understand what kind of data is being used.

Example:

```java
int age = 22;
float salary = 25000.5f;
char grade = 'A';
String name = "Varsha";
```

Here:

* `int` stores integer values.

* `float` stores decimal values.

* `char` stores a single character.

* `String` stores a sequence of characters.

### 2\. Types of Data Types in Java

Java data types are classified into two types:

Data Types

Primitive

8 types

Non-Primitive

Reference types

Primitive: byte, short, int, long, float, double, char, boolean

Non-Primitive: String, Arrays, Classes, Interfaces, etc.

### 3\. Primitive Data Types

Primitive data types are predefined data types in Java.

Java has 8 primitive data types.

| Data type | Size          | Example           |
| --------- | ------------- | ----------------- |
| byte      | 1 byte        | byte a = 10;      |
| short     | 2 bytes       | short a = 100;    |
| int       | 4 bytes       | int a = 1000;     |
| long      | 8 bytes       | long a = 10000L;  |
| float     | 4 bytes       | float a = 10.5f;  |
| double    | 8 bytes       | double a = 20.55; |
| char      | 2 bytes       | char a = 'A';     |
| boolean   | JVM-dependent | boolean a = true; |

### A. Integer Data Types

These are used to store whole numbers.

1\. byte

* Size: 1 byte (8 bits)

* Range: -128 to 127

```java
byte a = 100;
System.out.println(a);
```

2\. short

* Size: 2 bytes (16 bits)

* Range: -32,768 to 32,767

```java
short a = 20000;
```

3\. int

* Size: 4 bytes (32 bits)

* Range: -2³¹ to 2³¹ - 1

```java
int a = 100000;
```

4\. long

* Size: 8 bytes (64 bits)

* Range: -2⁶³ to 2⁶³ - 1

```java
long a = 9876543210L;
```

### B. Floating-Point Data Types

These are used to store decimal values.

5\. float

* Size: 4 bytes (32 bits)

* Use `f` or `F` at the end.

```java
float salary = 25000.5f;
```

6\. double

* Size: 8 bytes (64 bits)

* Used for more precision than float.

* Default type for decimal literals.

```java
double price = 25000.5678;
```

### C. Character Data Type

7\. char

* Size: 2 bytes (16 bits)

* Stores a single character.

* Uses single quotes.

```java
char grade = 'A';
```

### D. Boolean Data Type

8\. boolean

* Stores only two values: `true` or `false`.

* Used in conditional statements.

```java
boolean result = true;
```

### 4\. Non-Primitive Data Types

Non-primitive data types are also called reference data types.

* They are used to store references to objects.

* They can have methods.

* They can be created by programmers or provided by Java.

Examples:

### 1\. String

```java
String name = "Varsha";
System.out.println(name);
```

### 2\. Array

```java
int a[] = {10, 20, 30};

System.out.println(a[0]);
```

### 3\. Class

```java
class Student
{
    int age = 22;
}
```

### 4\. Interface

```java
interface Demo
{
    void display();
}
```

### 5\. Difference Between Primitive and Non-Primitive

| Primitive                               | Non-Primitive                            |
| --------------------------------------- | ---------------------------------------- |
| Predefined by Java                      | Built-in or user-defined reference types |
| 8 types                                 | Many types                               |
| Stores actual values                    | Stores references                        |
| Cannot call methods on primitive values | Can have methods                         |
| Cannot be null                          | Can be null                              |
