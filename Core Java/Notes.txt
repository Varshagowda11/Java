Types of Programming Languages
1. Machine Level Language (Low-Level Language)

2. Types of Programming Languages
1. Machine Level Language (Low-Level Language)
- It is understandable by machines.
- It is a binary language.
- It has two representatives:
  - 0
  - 1
- It is near to machines and far from humans.

2. Assembly Level Language (Mid-Level Language)
- It is in a human-readable format.
- We have a set of instructions called mnemonics and keywords (predefined words).
- Examples: ADD, MOV, SUB, MUL, etc.
Difficulties:
- Machines cannot understand Assembly Language directly.
- We need to convert Assembly Language (AL) into Machine Level Language (MLL).
- We need software called an Assembler.
- 8086 instructions are an example.
Advantages:
- Easier for humans to write and understand.

3. High-Level Language
- It is in a human-readable format.
- Examples: Java, Python, C, C++ and C#.
- Machine cannot understand High-Level Language directly.
- We need to convert High-Level Language (HLL) into Machine Level Language (MLL).
- We need software:
  - Compiler
  - Interpreter
Advantages:
- Easier to learn.
- Easier to write.
- Easier to debug and maintain.

Two Types of HLL
1. POPL
2. OOPL

POPL – Procedure Oriented Programming Language
- Focuses on procedures/functions.
- Example: C.
- No OOPS.
OOPL – Object Oriented Programming Language
- Focuses on objects.
- Examples: Java, Python, C++.
Java is a High-Level Object-Oriented Programming Language.

3. He needed a team and called it the Green Team.
4. He started a project. The project name was Green Project.

Naming of Java
1. One day, they stood outside a company with a coffee shop. They thought their programming language idea would grow like a tree.
2. So, they kept the tree name called Oak.
3. Oak was already a company name with a business, so they could not continue using it.
4. Then they changed the name in 1995 to Java.

### Java Notes – Variables in Java

### 1\. What is a Variable?

A variable is a container used to store data in a program.

* It is used to store values.

* Every variable has a name and a data type.

* The value of a variable can be changed during program execution.

Syntax:

```java
dataType variableName = value;
```

Example:

```java
int age = 22;
String name = "Varsha";
```

Here:

* `int` – Data type

* `age` – Variable name

* `22` – Value

### 2\. Types of Variables in Java

Based on where they are declared, variables are mainly classified into three types:

* Local Variable

* Instance Variable

* Static Variable

Sometimes, instance and static variables are collectively called global variables in beginner-level explanations. However, Java technically calls them fields or member variables.

### 3\. Local Variable

Definition: A variable declared inside a method, constructor or block is called a local variable.

Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int a = 10;  // Local variable
        int b = 20;  // Local variable

        System.out.println(a);
        System.out.println(b);
    }
}
```

Characteristics:

* Declared inside a method, constructor or block.

* Scope is limited to the block where it is declared.

* Memory is associated with method/block execution.

* No default value is provided.

* We must initialize it before using it.

### 4\. Global Variables

Global variables are commonly used to refer to variables declared inside a class but outside methods.

There are two types:

### A. Instance Variable (Non-static Variable)

Definition: A variable declared inside a class but outside methods, without using the `static` keyword, is called an instance variable.

Example:

```java
class Student
{
    int age = 22;  // Instance variable

    public static void main(String[] args)
    {
        Student s = new Student();

        System.out.println(s.age);
    }
}
```

Output:

```text
22
```

Characteristics:

* Declared inside a class and outside methods.

* Does not use the `static` keyword.

* Each object gets its own copy.

* Gets a default value.

* Accessed using an object reference.

### B. Static Variable (Class Variable)

Definition: A variable declared inside a class using the `static` keyword is called a static variable.

Example:

```java
class Student
{
    static String college = "DBIT";

    public static void main(String[] args)
    {
        System.out.println(Student.college);
    }
}
```

Output:

```text
DBIT
```

Characteristics:

* Declared inside a class using `static`.

* Only one shared copy exists per class (per class loader).

* Memory is associated with the class.

* Gets a default value.

* Can be accessed using the class name.

### 5\. Difference Between Local, Instance and Static Variables

| Feature       | Local                     | Instance         | Static       |
| ------------- | ------------------------- | ---------------- | ------------ |
| Declaration   | Inside method/block       | Inside class     | Inside class |
| Keyword       | No special keyword        | No static        | static       |
| Memory        | During execution          | With object      | With class   |
| Default value | No                        | Yes              | Yes          |
| Copy          | Per declaration/execution | Per object       | Shared       |
| Access        | Directly within scope     | Object reference | Class name   |

### 6\. One Program to Understand All Three

```java
class VariableDemo
{
    int a = 10;          // Instance variable
    static int b = 20;  // Static variable

    public static void main(String[] args)
    {
        int c = 30;      // Local variable

        VariableDemo obj = new VariableDemo();

        System.out.println(obj.a);
        System.out.println(b);
        System.out.println(c);
    }
}
```

Output:

```text
10
20
30
```

A data type specifies what type of value a variable can store.

* It defines the size of data.

* It specifies the type of value stored in a variable.

* It helps the compiler understand what kind of data is being used.

Example:

```java

float salary = 25000.5f;
char grade = 'A';
String name = "Varsha";
```

Here:

* `int` stores integer values.

* `float` stores decimal values.

* `char` stores a single character.

* `String` stores a sequence of characters.

### Java Notes – Decision-Making Statements

### 1\. What is a Decision-Making Statement?

A Decision-Making Statement is used to make decisions based on conditions in a Java program.

* It checks whether a condition is true or false.

* If the condition is true, one block of code executes.

* If the condition is false, another block may execute.

Example: If a student gets marks greater than or equal to 35, print Pass; otherwise, print Fail.

### 2\. Types of Decision-Making Statements

There are 5 commonly used forms:

* if statement

* if-else statement

* if-else-if ladder

* Nested if statement

* switch statement

### 3\. if Statement

Definition: The if statement executes a block of code only when the condition is true.

Syntax:

```java
if(condition)
{
    // statements
}
```

Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int age = 22;

        if(age >= 18)
        {
            System.out.println("Eligible to vote");
        }
    }
}
```

Output:

```text
Eligible to vote
```

### 4\. if-else Statement

Definition: The if-else statement executes one block when the condition is true and another block when the condition is false.

Syntax:

```java
if(condition)
{
    // true block
}
else
{
    // false block
}
```

Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int num = 10;

        if(num % 2 == 0)
        {
            System.out.println("Even");
        }
        else
        {
            System.out.println("Odd");
        }
    }
}
```

Output:

```text
Even
```

### 5\. if-else-if Ladder

Definition: It is used to check multiple conditions one by one.

Syntax:

```java
if(condition1)
{
    // statements
}
else if(condition2)
{
    // statements
}
else if(condition3)
{
    // statements
}
else
{
    // statements
}
```

Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int marks = 85;

        if(marks >= 90)
        {
            System.out.println("A Grade");
        }
        else if(marks >= 75)
        {
            System.out.println("B Grade");
        }
        else if(marks >= 35)
        {
            System.out.println("C Grade");
        }
        else
        {
            System.out.println("Fail");
        }
    }
}
```

Output:

```text
B Grade
```

### 6\. Nested if Statement

Definition: An if statement inside another if statement is called a nested if statement.

Example:

### 7\. switch Statement

Definition: The switch statement is used to select one block of code from multiple choices based on an expression's value.

Syntax:

```java
switch(expression)
{
    case 1:
        // statements
        break;

    case 2:
        // statements
        break;

    default:
        // statements
}
```

Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int day = 2;

        switch(day)
        {
            case 1:
                System.out.println("Monday");
                break;

            case 2:
                System.out.println("Tuesday");
                break;

            case 3:
                System.out.println("Wednesday");
                break;

            default:
                System.out.println("Invalid day");
        }
    }
}
```

Output:

```text
Tuesday
```

1. What is a Loop?
A loop is a programming statement used to execute a block of code repeatedly until a given condition becomes false.
- It is used to reduce code repetition.
- It saves time and effort.
- It executes statements repeatedly based on a condition.
Example: Printing numbers from 1 to 10.
2. Types of Loops in Java
There are 3 main types of loops:
1. for loop
2. while loop
3. do-while loop
Other forms include nested loops and enhanced for-each loops.

3. for Loop
Definition: A for loop is used when we know how many times we want to execute a block of code.

Syntax:
for(initialization; condition; increment/decrement)
{
    // statements
}


Example:
class Demo
{
    public static void main(String[] args)
    {
        for(int i = 1; i <= 5; i++)
        {
            System.out.println(i);
        }
    }
}


Output:
1
2
3
4
5


Explanation:
- Initialization: int i = 1
- Condition: i <= 5
- Increment: i++
4. while Loop
Definition: A while loop executes a block of code as long as the given condition is true.

Syntax:
initialization;

while(condition)
{
    // statements
    increment/decrement;
}


Example:
class Demo
{
    public static void main(String[] args)
    {
        int i = 1;

        while(i <= 5)
        {
            System.out.println(i);
            i++;
        }
    }
}


Output:
1
2
3
4
5


5. do-while Loop
Definition: A do-while loop executes the statements at least once, even if the condition is false.

Syntax:
initialization;

do
{
    // statements
    increment/decrement;
}
while(condition);


Example:
class Demo
{
    public static void main(String[] args)
    {
        int i = 1;

        do
        {
            System.out.println(i);
            i++;
        }
        while(i <= 5);
    }
}


Output:
1
2
3
4
5



6. Difference Between for, while and do-while
for loop	while loop	do-while loop
Entry-controlled	Entry-controlled	Exit-controlled
Checks condition first	Checks condition first	Checks condition after execution
Initialization, condition and update in one statement	Written separately	Written separately
May execute zero times	May execute zero times	Executes at least once

7. Nested Loop
Definition: A loop inside another loop is called a nested loop.

Example:
class Demo
{
    public static void main(String[] args)
    {
        for(int i = 1; i <= 3; i++)
        {
            for(int j = 1; j <= 3; j++)
            {
                System.out.print("* ");
            }

            System.out.println();
        }
    }
}


Output:
* * *
* * *
* * *


8. Enhanced for Loop (For-Each Loop)
Definition: The enhanced for loop is used to traverse arrays and collections easily.

Syntax:
for(dataType variable : array)
{
    // statements

### Java Notes – Type Casting in Java

### 1\. What is Type Casting?

Type Casting is the process of converting one data type into another data type.

* It is used to convert values from one data type to another.

* It helps when we want to perform operations using different data types.

Example:

```java
int a = 10;
double b = a;
```

Here, `int` is converted into `double`.

### 2\. Types of Type Casting in Java

There are two types of type casting:

* Widening Casting (Implicit Casting)

* Narrowing Casting (Explicit Casting)

Type Casting

Widening

Small → Large

Automatic

Narrowing

Large → Small

Manual

### 3\. Widening Casting (Implicit Casting)

Definition: Converting a smaller data type into a larger data type is called widening casting.

* It happens automatically.

* No need to mention the target data type.

* There is generally no loss of information when converting between these numeric types.

### Order of Widening

byte

short

int

long

float

double

Smaller to larger (general widening order)

Note: `char` can also be widened to `int`, `long`, `float` and `double`.

### Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        int a = 10;

        double b = a;

        System.out.println(a);
        System.out.println(b);
    }
}
```

Output:

```text
10
10.0
```

Explanation:

* `a` is an integer.

* `b` is a double.

* Java automatically converts `int` into `double`.

### 4\. Narrowing Casting (Explicit Casting)

Definition: Converting a larger data type into a smaller data type is called narrowing casting.

* It is performed manually.

* We need to specify the target data type.

* There may be a loss of data.

### Syntax:

```java
targetDataType variable = (targetDataType) value;
```

### Example:

```java
class Demo
{
    public static void main(String[] args)
    {
        double a = 10.75;

        int b = (int) a;

        System.out.println(a);
        System.out.println(b);
    }
}
```

Output:

```text
10.75
10
```

Explanation:

* `a` is a double.

* `b` is an integer.

* We manually convert double into int.

* The decimal part `.75` is lost.

### 5\. Difference Between Widening and Narrowing

| Widening                     | Narrowing                 |
| ---------------------------- | ------------------------- |
| Small to large               | Large to small            |
| Automatic                    | Manual                    |
| Implicit casting             | Explicit casting          |
| Usually no information loss  | May lose information      |
| No casting operator required | Casting operator required |

### 4\. Logical Operators in Java

Definition: Logical operators are used to combine two or more conditions. They return either `true` or `false`.

### Types of Logical Operators

| Operator | Name | Meaning | |---|---|---| | `&&` | Logical AND | True if both conditions are true | | `||` | Logical OR | True if at least one condition is true | | `!` | Logical NOT | Reverses the result |

### 1\. Logical AND (`&&`)

Returns `true` only when both conditions are true.

```java
int a = 10;
int b = 20;

System.out.println(a < b && a > 5);
```

Output:

```text
true
```

### 2\. Logical OR (`||`)

Returns `true` if at least one condition is true.

```java
int a = 10;
int b = 20;

System.out.println(a > b || a < b);
```

Output:

```text
true
```

### 3\. Logical NOT (`!`)

Reverses the condition's result.

```java
int a = 10;

System.out.println(!(a > 5));
```

Output:

```text
false
```

### Truth Table

| A     | B     | A && B | A \|\| B |
| ----- | ----- | ------ | -------- |
| true  | true  | true   | true     |
| true  | false | false  | true     |
| false | true  | false  | true     |
| false | false | false  | false    |

Important points:

* `&&` means both conditions must be true.

* `||` means at least one condition must be true.

* `!` reverses true to false and false to true.

* `&&` and `||` use short-circuit evaluation in Java.
